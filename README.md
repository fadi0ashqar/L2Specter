# L2Specter V1 - Layer 2 Recon & Identity Spoofing Suite

L2Specter is a specialized utility designed for network enumeration and hardware identity manipulation on Windows systems. It operates at the Data Link layer to bypass standard filtering and gain deep network visibility.

## 🛡️ Key Capabilities
* **Active ARP Hunting:** High-speed host discovery via raw frame injection.
* **Passive Monitoring:** Stealth packet sniffing to map the network without broadcasting.
* **Identity Mutation:** MAC address spoofing with automated adapter power-cycling.
* **Service Discovery:** Multi-threaded TCP port mapping (SSH, RDP, SMB, HTTP).

## ⚠️ Requirements
* **Npcap:** Must be installed in "WinPcap API-compatible Mode". [Download here](https://nmap.org/npcap/).
* **Privileges:** Administrator rights are required for registry and raw socket operations.
